## Compléter la collection

- Ajouter les nouvelles images dans `assets/media/`, avec un nom descriptif et des dimensions explicites dans le HTML.
- Conserver le format et le cadrage d’origine pour les photos de documentation.
- Ne pas agrandir les anciennes images de 357 × 358 pixels : utiliser les futures photos haute résolution lorsqu’elles seront disponibles.
- Bubble Sea est confirmé par le propriétaire comme projet 2024–2025. Aucune photographie de Bubble Sea n’a encore été fournie.
- `manifest.json` conserve la provenance, les dimensions et un texte alternatif suggéré.
